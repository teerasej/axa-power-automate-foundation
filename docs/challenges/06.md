# Challenge 6 — Controlled-document approval

![A control owner checks a draft document before a clean copy enters a separate folder.](/images/challenge-06-controlled-document-approval.png)

## Scenario

A fictional document in Pending Review is modified. A control owner must approve it before a copy is created in a separate Approved folder outside the watched folder tree.

Use fictional information only. These are training examples, not organisational policies. This challenge is a physical-card simulation; no software account or paid licence is required.

## Goal

After human approval, create a copy in Approved without writing into the watched source folder.

## What you need

Supplied Flow cards, post-its and your group. Use only available cards; notes may explain repeated uses, roles or inputs.

## Normal test case

File: procedure-draft.txt, smaller than 50 MB. Source: Pending Review. Decision: Approve. Destination: Approved, outside the source folder tree.

## Steps

1. Identify the file-modified event and source folder.
2. Place the human approval before the approved file creation.
3. Identify the fixed file name, its content and the separate destination.
4. Walk the Approve case and request a basic-sequence check.

## Check your result

A human approval gates the copy, and the destination is outside the watched folder tree. The fixed fictional file name and content are available.

An instructor/TA awards one point for an accepted basic sequence, only once for this challenge. Detailed configuration and a complete exception route are not required. Hints and retries are allowed without deductions.

::: details Optional exception discussion

If the decision is Reject, how should the coordinator hear about it without a new approved file? Discuss the documented size limit; recalling it is not scored.


:::
