# Challenge 1 — Email attachment intake

![An employee organises a document and a picture attachment into one folder.](/images/challenge-01-email-attachment-intake.png)

## Scenario

The team receives request emails that may include several supporting documents. The workflow must check whether an email has attachments. If it does, every attachment must be saved in the designated folder. If it does not, the sender must be asked to provide the missing documents.

Use fictional information only. Do not use real names, customer information, case numbers, or documents.

<span id="your-challenge"></span>
<span id="arrange-and-explain"></span>

## Challenge

Arrange the Flow cards to show the process from receiving the email to one of these outcomes:

- Email with attachments: every attachment is saved.
- Email without attachments: the sender receives a request for the missing documents.

> **Boundary:** Use only the Trigger, Action, and Control cards in the physical deck. Use sticky notes only for responsible roles, business decisions, steps that require a physical card to be repeated, and unresolved checks. Do not write a new Trigger or Action name on a sticky note.

> **For this game:** The complete workflow includes both outcomes. Build and explain the normal path under **Required for 1 point** first. The other outcome is optional and earns no extra points.

<span id="try-the-normal-case"></span>
<span id="check-your-result"></span>

## Checkpoint

**Required for 1 point:** Start with the incoming email and show how every supplied attachment is saved in the designated folder. Trace the attachment content through the cards and repeat the necessary steps for every file.

Explain your valid starting Trigger, connected supplied cards and normal result to the instructor/TA. Only the instructor/TA records the accepted point.

**Optional discussion:** Walk through an email with no attachments. Show how the sender receives a clear request for the missing documents.

You can earn the point without completing the optional discussion or recalling a technical limitation.
