# Challenge 1 — Email attachment intake

![An employee organises a document and a picture attachment into one folder.](/images/challenge-01-email-attachment-intake.png)

## Scenario

The team receives request emails with supporting documents. When documents are present, save every attachment in the designated folder. If there are none, a missing-document request is useful follow-up.

Use fictional information only. These are training examples, not organisational policies. This challenge is a physical-card simulation; no software account or paid licence is required.

## Goal

Save both fictional attachments in the destination folder.

## What you need

Supplied Flow cards, post-its and your group. Use only available cards; notes may explain repeated uses, roles or inputs.

## Normal test case

An email titled Service case documents contains request.pdf and evidence.jpg. Both files must be saved.

## Steps

1. Identify the event that starts the process.
2. Show how the same file-handling steps run for each attachment.
3. Identify where the file name and content come from, using plain language.
4. Walk both attachments through the cards and request a basic-sequence check.

## Check your result

Two attachments reach the folder; the arrangement does not save only the first or create an empty file.

An instructor/TA awards one point for an accepted basic sequence, only once for this challenge. Detailed configuration and a complete exception route are not required. Hints and retries are allowed without deductions.

::: details Optional exception discussion

What should happen when an email has no attachments? Add a missing-document email route if time permits.


:::
